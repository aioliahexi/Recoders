# 摄像机系统 全面回归测试用例清单

> 范围：Jetson Xavier NX 部署的全部功能（含历轮开发与修复项）。
> 分 9 大模块；`debug_check.sh` 的 13 项仅是"设备/硬编/服务/协议"快速自检，本清单为完整回归矩阵。
> 执行前准备：2 台真实 UVC 相机（USB 1-2.2、1-2.4），Mac 与 Jetson 同网段，api_key=`camera2026`。

## A. 快速自检（debug_check，13 项基线）

| 编号 | 用例 | 步骤 | 预期 |
|---|---|---|---|
| A-01 | 设备发现命令 | `camera_server --list` | 正常输出，发现 ≥1 UVC |
| A-02 | UVC 相机枚举 | 同上 | `cam /dev/videoN` 存在且 formats>0 |
| A-03 | NVENC 可用 | 自检读取 nvenc 时钟 | 时钟 >0 |
| A-04 | GStreamer 硬编插件 | `gst-inspect-1.0 nvv4l2h264enc` | 插件在 |
| A-05 | 服务运行 | `systemctl is-active camera_server` | active |
| A-06 | HTTP 监听 | `ss -tlnp | grep 8000` | 监听 |
| A-07 | RTSP 监听 | `ss -tlnp | grep 8554` | 监听 |
| A-08 | health | `GET /health` | code=0（免鉴权） |
| A-09 | cameras 接口 | `GET /api/v1/cameras` | code=0 |
| A-10 | 抓拍 | `POST .../photo` | code=0，latest.jpg 生成 |
| A-11 | 录像列表 | `GET .../recordings` | 有数据 |
| A-12 | RTSP 拉流 | ffprobe `rtsp://ip:8554/<相机名>` | codec_name=h264 |
| A-13 | ONVIF | GetDeviceInformation | 正常返回 |

## B. 采集与编码（性能基线）

| 编号 | 用例 | 步骤 | 预期 |
|---|---|---|---|
| B-01 | 两路 1080p30 | 录像 30s，看 `fps_actual` | 每路 ≥29fps |
| B-02 | CPU 预算 | `top`/`tegrastats` | 2 路总 CPU 可接受（OSD 叠加后 ~40% 内） |
| B-03 | OSD 叠加 | 抽帧查看 | 左上时间戳、左下相机名（config.json 名） |
| B-04 | 时间戳准确性 | 对比帧时间与当前时间 | 秒级一致（`%Y-%m-%d %H:%M:%S`） |
| B-05 | 断线重连 | 拔相机再插 | 3s 重连恢复，录像续写 |
| B-06 | 第二节点不误注册 | 热插拔后相机列表 | 不出现"Web Camera"幻影（无格式节点被跳过） |
