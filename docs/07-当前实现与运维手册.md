# 当前实现与运维手册（Jetson Xavier NX）

> 本文档描述 **当前已实现并部署** 的系统（2026-08，与代码同步）；`01~06` 为早期设计/调研文档。

## 1. 系统架构

```
USB UVC 相机(OV9734/Sunplus) --/dev/videoN--> camera_server(C++17, :8000)
                                                  ├─ GStreamer 采集: v4l2src→jpegdec→OSD→nvvidconv→nvv4l2h264enc(NVENC)
                                                  ├─ 分段 fMP4 录像 + SQLite 索引(/data/camera/db/records.db)
                                                  ├─ 抓拍 JPEG → /data/camera/photos/<相机名>/
                                                  ├─ RTSP :8554 / ONVIF / RESTful / MJPEG 实时流
                                                  ├─ 热插拔线程(2s) + 操作日志(oplog)
                                                  └─ Node.js Web(:8081, webui/) 代理 /api、/onvif
```

- 进程：`camera_server.service`（C++，:8000/:8554）+ `camera-web.service`（Node，:8081），均开机自启。
- 数据目录：`data_dir=/data/camera`（录像 `recordings/<相机名>/`、照片 `photos/<相机名>/`、DB `db/`）。

## 2. 配置文件（统一 config.json）

> **单一 JSON**：系统配置 + 用户配置（NVR 名称 / 相机 / 免鉴权开关）全部在**一个文件**
> `/opt/camera_server/config.json` 中管理；Web 前端（Node）也从同一文件读取 `api_key`/`data_dir`/后端端口。
> 旧 `config.ini` 与 `data_dir/recorder.json`（及更早 3 个 json）**首次启动自动迁移并入并删除**。

```json
  "quota_mb": 200000,
  "segment_time_s": 60,
  "encoder": "auto",
  "http_port": 8000,
  "rtsp_port": 8554,
  "api_key": "camera2026",
  "host_ip": "",
  "autostart": true,
  "onvif_enabled": true,
  "onvif_discovery": true,
  "nvr_name": "camera_server NVR",
  "rest_public": false,
  "cameras": [
    {
      "id": 1,
      "uuid": "",
      "name": "CAM01",
      "device": "/dev/video0",
      "mock": false,
      "width": 1920,
      "height": 1080,
      "fps": 30,
      "input_format": "mjpeg",
      "bitrate_kbps": 3000,
      "gop": 60,
      "capture": "gst",
      "osd": true,
      "enabled": true
    },

    {
      "id": 2,
      "uuid": "",
      "name": "CAM02",
      "device": "/dev/video2",
      "mock": false,
      "width": 1920,
      "height": 1080,
      "fps": 30,
      "input_format": "mjpeg",
      "bitrate_kbps": 3000,
      "gop": 60,
      "capture": "gst",
      "osd": true,
      "enabled": true
    }
  ]
}
```

- **系统配置**：`data_dir / quota_mb / segment_time_s / encoder / http_port / rtsp_port / api_key / host_ip / autostart / onvif_enabled / onvif_discovery`。
- **用户配置**：`nvr_name`（NVR 名称）、`rest_public`（免鉴权 REST 调试开关）、`cameras[]`（相机 UUID 绑定 + 参数）。
- 运行时写回（改名 / 添加删除相机 / 热插拔注册 / 免鉴权开关 / NVR 名称）均**原子写**该文件，且**保留 system 字段**；
  `id` 可省略（自动从 1 顺序分配，跳过已占用 id），`uuid` 为空表示待设备识别绑定。
- Node Web（`webui/server.js`）默认从该文件（部署位置为 webui 上级目录）读取 `api_key`/`data_dir`/`http_port`，
  与本目录 `webui/config.json`（仅 `port`/`backend`）解耦；旧 `webui/config.json` 里的 `api_key`/`data_dir` 字段仍兼容兜底。
- 迁移：传入旧 `config.ini`（或同目录存在 `config.ini`）时自动生成同名 `config.json` 并接管；
  存在旧 `data_dir/recorder.json` 等时自动合并 `cameras/nvr_name/rest_public` 后删除。
- 模板：`deploy/jetson/config.jetson.example.json`（通用）、`config.real.example.json`（2 路 1080p gst 实测）。

## 3. 相机 UUID 与热插拔

- **UUID 派生**：有序列号 → `VID:PID+序列号`（换 USB 口不变）；无序列号 → 含物理端口（换口由重绑定处理）。
- **热插拔**（线程每 2s）：
  - 新 UUID 且**有采集格式** → 自动注册相机（建目录/管道/写入统一 config.json/开始录像），Web 每 5s 自动刷新；
  - 拔线 → 保留配置、`online=false`（未连接）、fps 归零，历史录像/照片仍可浏览；
  - 插回同 UUID → 自动恢复信号；设备换 `/dev/videoN` → 自动重配；
  - **无序列号相机换 USB 口**（新 UUID 但同型号，且恰好一台同型号离线）→ 自动重绑定，保持原配置/名称/历史（日志 `camera_rebind`）。
- 手动添加/删除：Web 相机配置页（添加弹窗用 `/api/v1/system/discover`）或 `POST/DELETE /api/v1/cameras`。

## 4. 录像与回放

- 分段 **1 分钟一段**（`segment_time_s=60`），按开始时间命名（`YYYYMMDD_HHMMSS.mp4`）；fMP4（moov 前置 + 按关键帧/2s 分片）录制中也可实时播放；HTTP Range 拖动。
- SQLite 索引（`recordings` 表，含 `camera_uuid` 绑定设备）；配额循环回收。
- 回放：Web 录像回放页（选相机/日期 → 片段 → 浏览器直接播放）。

## 4.1 照片事件标签（SQLite）

- 事件标签存 **SQLite `photos` 表**（tag/source），文件名保持纯净 `<ts>.jpg`；照片**仅在手动或事件触发时生成**（无自动抓拍）。
- 抓拍：`POST /api/v1/cameras/{id}/photo` body `{"quality":90,"tag":"入侵报警","source":"event"}`。
- 筛选：`GET .../photos?tag=<标签>`；标签列表 `GET .../photos/tags`；索引与磁盘自动同步（外部删除清孤儿行、新文件回填默认"手动抓拍"）。

## 5. OSD 画面叠加

gst 链路在 NVENC 前插入 `clockoverlay`(时间戳 `%Y-%m-%d %H:%M:%S` 左上) + `textoverlay`(相机名 左下)：
录像、RTSP、实时预览统一叠加；`[camera] osd=true/false` 每路开关；预览从叠加分支降采样 jpegenc(640x360)。

## 6. 操作日志

系统动作（删照片/清理数据/改名/参数/录像启停/抓拍/ONVIF/NVR 名称/服务启停/相机添加删除/换口重绑定）写入 SQLite `oplog` 表；
Node 服务动作写 `oplog_node.jsonl`；`GET /api/v1/system/logs` 合并查询，系统设置页展示。

## 7. NFS 共享（外部直接读取录像/照片）

```bash
sudo /opt/camera_server/deploy/jetson/setup_nfs.sh          # 默认共享 /data 给 192.168.0.0/24
mount -t nfs <jetson-ip>:/data /mnt/nfs
# 录像 <mount>/camera/recordings/<相机名>/；照片 <mount>/camera/photos/<相机名>/
```
> 免账号密码=IP 白名单；改网段编辑 `/etc/exports` 后 `exportfs -ra`。

## 8. mDNS 局域网发现 + SMB（macOS Finder 浏览）

```bash
sudo /opt/camera_server/deploy/jetson/setup_samba.sh   # SMB 共享 /data（guest）
sudo /opt/camera_server/deploy/jetson/setup_mdns.sh    # Avahi 广播（含 _smb._tcp）
```
- Avahi 广播：`_smb._tcp`(445，Finder 网络栏)、`_http._tcp`(8081)、`_rtsp._tcp`(8554)、`_camera-server._tcp`(8000)。
- **macOS Finder**：「前往 → 网络」可见设备，点开以游客连接，浏览 `/data`（录像/照片）。
- 命令行：`dns-sd -B _camera-server._tcp`；Safari 书签→Bonjour 打开 Web 界面。
- > 说明：`_http/_rtsp/_camera-server` 类型 Finder 网络栏**不显示**（那是给 Safari/VLC/App 的），浏览文件需 SMB（`_smb._tcp`）。

## 9. 常用运维

```bash
systemctl status camera_server camera-web        # 服务状态
systemctl restart camera_server                  # 重启（Web 系统页也有 启动/停止/重启）
journalctl -u camera_server -f                   # 实时日志
bash /opt/camera_server/deploy/jetson/debug_check.sh   # 13 项快速自检
bash /opt/camera_server/deploy/jetson/test_all.sh         # 56 项全面回归（--destructive 含破坏性用例）
bash /opt/camera_server/deploy/jetson/make_udev_rules.sh  # 生成稳定 /dev/cam0x 设备名(可选)
lsusb -t; ls /dev/video*                          # 确认相机枚举
```

### 故障排查

| 现象 | 排查 |
|---|---|
| 相机显示未连接 | `lsusb`/`ls /dev/video*`；`journalctl -u camera_server | grep gstcap`；插回同口/UUID 自动恢复 |
| 误注册成新相机 | 有序列号相机换口 UUID 不变；无序列号相机换口 → 自动重绑定（`grep camera_rebind`） |
| 录像无法播放 | 确认 fMP4 分段（`moov` 在文件头）；HTTP Range 下载测试 |
| Web 打不开 | `systemctl is-active camera-web`；8081 端口 |
| 画面无 OSD | `[camera] osd=true`；重启后生效 |
| 数据被清理 | 查 `GET /api/v1/system/logs` 中 `data_clear` 记录（操作日志留痕） |

## 10. 代码结构（camera_cpp/src）

```

camera_manager.{h,cpp}   # 相机 launch/remove 共用逻辑

db.{h,cpp}               # SQLite 录像索引 + 操作日志
device/device_discovery.*# 多厂商 UVC 发现 + UUID

media/gst_capture.cpp    # GStreamer 全链路采集 + OSD
media/ffmpeg_pipeline.cpp# FFmpeg 路径（RK 等）
media/recorder.{h,cpp}   # 分段 fMP4 + 配额
media/v4l2_controls.*    # V4L2 图像控件
net/http_server.{h,cpp}  # 自研 HTTP（含流式路由）
rest/rest_service.cpp    # RESTful 全部接口（见根 README 独立章节）
rtsp/rtsp_server.cpp     # RTSP H.264
onvif/onvif_service.cpp  # ONVIF SOAP + WS-Discovery
web/web_ui.cpp           # 旧简易页（当前以 Node webui 为主）
```
